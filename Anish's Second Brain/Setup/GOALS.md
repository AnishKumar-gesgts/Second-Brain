Anish's Second Brain — Goals

Purpose

Maintain a pragmatic, action-first vault that converts research, coursework, and project artifacts into reproducible deliverables and outreach-ready summaries.

Top-level Goals
- Reproducible Research Outputs: For each major simulation or research project produce a documented repository, reproducible run instructions, a one‑page summary, and a poster or outreach artifact.
- Coursework & Credits: Keep AP/IVC coursework on track and map earned credits clearly for applications and transcripts.
- Outreach Pipeline: Produce tailored one‑pagers and saved outreach drafts; maintain a replies log and track outreach responses.

Planning Cadence
- 6–8 week milestone windows for major projects (break into weekly tasks).
- Weekly check‑ins: use the `weekly-update` flow to capture status, blockers, and next actions.

Success Criteria & Deliverables
- Each active project has a milestone plan, an `Assets Index`, and a single next action that can be completed in one session.
- A project is "shipped" when its repo is documented, reproducible, and has a one‑page summary suitable for outreach.

Risks & Mitigations
- Time budget overload: protect focused blocks, prune low‑value tasks, and enforce single next actions per project.
- Limited mentor feedback: prepare concise one‑pagers with explicit asks to solicit targeted reviews.

Immediate Next Actions
1. Create an `Assets Index` for the top two research projects (list key files, data, and where reproducible runs live). — Effort: 1–2 sessions.
2. Run the reproducibility checklist for the highest‑priority project and record missing steps as concrete TODOs. — Effort: 1–3 sessions.
3. Draft a one‑page outreach summary for the top project and save it as a draft in the vault. — Effort: 1 session.
4. Package research for applications and portfolio: create a GitHub repo with reproducible code/notebooks, a clear `README`, a concise one‑page summary, and a poster PDF; link these artifacts in application supplements and outreach. — Effort: 2–4 sessions.
5. Prepare the physics-olympiad pipeline: study F=MA past exams and timed problem sets weekly, join a coach or study group, and aim for qualifier scores (USAPhO/AAPT) to strengthen theoretical physics credentials. — Effort: ongoing (weekly).
6. Secure strong recommendations: request a letter from your physics teacher now and plan for a research-mentor letter (SRA mentor). Provide each recommender a 1‑page summary and bullet talking points highlighting independence, technical contribution, and impact. — Effort: 1 session + SRA term.
7. Publish and present results: produce a short reproducible report or preprint-style writeup, upload code to GitHub with a polished `README`, and produce a poster for science-fair and outreach use. — Effort: 1–2 sessions.
8. Assemble a balanced application list and strategy: choose 2 clear safeties, 4–6 targets, and 4–6 reaches; map each school's key themes to short essay points and identify recommender fit. — Effort: 1–2 sessions.
