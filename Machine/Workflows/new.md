# Workflow: /new

Capture and route an idea with minimal friction.

1. Classify the input as a task, note, project update, reference, or unresolved inbox item.
2. Suggest the smallest appropriate destination in the current vault structure.
3. In read-only mode, show the proposed title, location, and content.
4. In edit-enabled mode, create or update the file after the destination is clear.
5. Keep the original wording when it carries useful nuance.
