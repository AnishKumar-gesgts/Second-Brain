# Workflow: /closeday

Close the day without creating busywork.

1. Read today's daily note.
2. Identify completed work, unfinished tasks, blockers, and useful decisions.
3. Recommend which incomplete tasks should be carried forward, delegated, rescheduled, or dropped.
4. In read-only mode, present the closeout summary.
5. In edit-enabled mode, update the End of day section and carry forward only the approved tasks.
