# Workflow: /today

Build a practical plan using the live vault.

1. Get today's date in `YYYY-MM-DD` format.
2. Open or create `Daily Notes/YYYY-MM-DD.md` from `Templates/Daily Note.md`.
3. Read the three most recent daily notes and carry forward relevant unchecked tasks and blockers.
4. Scan open tasks in `Tasks/` and active work in `Projects/`.
5. Recommend one primary outcome, up to two supporting priorities, a small task list, and any timing risks.
6. In read-only mode, present the plan without editing files.
7. In edit-enabled mode, write the approved plan into today's daily note and append a timestamped activity-log entry.
